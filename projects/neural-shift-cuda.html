Parallelize the kernel aggregation behind learned denoisers, from gathering shifted pixels to reducing their weighted contributions.

The connection

Make learned kernel
aggregation practical.

Kernel denoisers restore each pixel by aggregating information from shifted neighbors with learned weights. This is the computational core of NECTR and related neural kernel denoisers.

A serial implementation processes shifts one at a time, repeatedly gathering pixels, evaluating the weight network, and updating a weighted numerator and normalization factor. This creates many small GPU operations and sequential accumulation steps.

I developed neural_shift_cuda to batch the shift-dependent work and implement aggregation with fused CUDA kernels. The extension integrates with the original NECTR models and attention-based kernel denoisers through model patches.

Let \(P_\pi\) denote a shift operator, \(\omega_\pi\) its predicted weight map, and \(\boldsymbol e\) the all-ones vector. In both cases, \(\mathcal Kx\) accumulates weighted pixels and \(\delta=\mathcal K\boldsymbol e\) accumulates their degrees. The symbols \(\odot\) and \(\oslash\) denote elementwise multiplication (the Hadamard product) and division, respectively.

Asymmetric kernel: all shifts

Predict weights for every shift in the full family \(\mathcal G\), including the identity. Each shift contributes once; its inverse may have an independently predicted weight map.

\[\mathcal Kx = \sum_{\pi\in\mathcal G} \omega_\pi\odot(P_\pi x), \quad \delta = \sum_{\pi\in\mathcal G} \omega_\pi, \quad \mathcal D(x) = (\mathcal Kx)\oslash\delta.\]

Symmetric kernel: inverse pairs

For cyclic shifts, let \(\mathcal I_+\) contain one representative from each nonidentity inverse pair, so \(\mathcal G=\{\pi_{\mathrm{id}}\}\mathbin{\dot\cup}\mathcal I_+ \mathbin{\dot\cup}\{\pi^{-1}:\pi\in\mathcal I_+\}\). Predict weights only for \(\{\pi_{\mathrm{id}}\}\mathbin{\dot\cup}\mathcal I_+\). Reuse each forward weight map in the inverse-shift contribution \(P_{\pi^{-1}}(\omega_\pi\odot x)=P_\pi^{\top}(\omega_\pi\odot x)\). Count the identity once, absorbing its fixed factor into its learned weight.

\[\mathcal Kx = \omega_{\mathrm{id}}\odot x + \sum_{\pi\in\mathcal I_+}\omega_\pi\odot(P_\pi x) + P_{\pi^{-1}}(\omega_\pi\odot x).\]

The degree includes both terms of every inverse pair and the identity. For a radius-\(R\) square window with no nonidentity self-inverse shifts, only \(J=2R^2+2R+1\) weight maps are predicted instead of \((2R+1)^2\). Symmetry here refers to \(\mathcal K\); NECTR additionally symmetrizes the normalized denoiser. The CUDA kernels handle the applicable boundary masks and preserve each aggregation formula, with reference checks within floating-point tolerances.

Implementation

GPU kernels with
PyTorch integration.

The operators provide autograd support for image and weight inputs, with pure-PyTorch reference implementations for CPU execution and equivalence checks. Supported patches connect the kernels to NECTR and related attention models.

The current implementation also includes promoted accumulation dtypes, 64-bit indexing, and an optional max-shifted normalized aggregation path for positive weights or logits. These support reliable evaluation of the same normalized weighted average.

Fixed-guide caches can reuse learned weights during repeated reconstruction steps, avoiding unnecessary recomputation while applying the kernel operator to changing iterates.
