Parallelize the kernel aggregation behind learned denoisers, from gathering shifted pixels to reducing their weighted contributions.

The connection

Make learned kernel
aggregation practical.

Kernel denoisers restore each pixel by aggregating information from shifted neighbors with learned weights. This is the computational core of NECTR and related neural kernel denoisers.

A serial implementation processes shifts one at a time, repeatedly gathering pixels, evaluating the weight network, and updating a weighted numerator and normalization factor. This creates many small GPU operations and sequential accumulation steps.

I developed neural_shift_cuda to batch the shift-dependent work and implement aggregation with fused CUDA kernels. The extension integrates with the original NECTR models and attention-based kernel denoisers through model patches.

$$ U = \sum_{\pi} w_{\pi} \odot (P_{\pi}\,x) + P_{\pi}(w_{\pi} \odot x);\quad Z = \sum_{\pi} w_{\pi}\,;\quad D = U \oslash Z $$

$P_{\pi}$ denotes a shift. The implementation also handles the applicable inverse-pair contributions and boundary masks. The acceleration preserves the aggregation formula; floating-point reductions are compared to the reference within numerical tolerances.

Explore the NECTR construction

  • Fused gathering

    Collect shifted inputs and validity masks together, including paired center/neighbor inputs for the weight predictor.

  • Batched weight prediction

    Process the stacked shifts through the neural network, reducing the overhead of repeated per-shift calls.

  • Parallel tree reduction

    Combine weighted image contributions and degrees across CUDA lanes using shared-memory reductions.

Implementation

GPU kernels with
PyTorch integration.

The operators provide autograd support for image and weight inputs, with pure-PyTorch reference implementations for CPU execution and equivalence checks. Supported patches connect the kernels to NECTR and related attention models.

The current implementation also includes promoted accumulation dtypes, 64-bit indexing, and an optional max-shifted normalized aggregation path for positive weights or logits. These support reliable evaluation of the same normalized weighted average.

Fixed-guide caches can reuse learned weights during repeated reconstruction steps, avoiding unnecessary recomputation while applying the kernel operator to changing iterates.
